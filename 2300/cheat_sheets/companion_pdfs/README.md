# Compiled Core companion PDFs

These seven PDFs are the verified student-facing builds of the companion TeX
sources in the parent `cheat_sheets` directory. They are committed even though
the repository normally ignores generated PDFs because the Overleaf project
needs stable, directly downloadable copies.

Rebuild with the Overleaf-compatible TeX Live 2025 toolchain, confirm that every
document is exactly four US-letter pages, visually inspect all pages, and then
replace these copies. Do not treat an old PDF in this directory as authoritative
when its TeX source has changed.
