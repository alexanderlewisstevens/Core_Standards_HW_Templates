# Compiled Core companion PDFs

These seven PDFs are the student-facing builds of the companion TeX sources
in the parent `cheat_sheets` directory. They are committed even though the
repository normally ignores generated PDFs because the Overleaf project needs
stable, directly downloadable copies.

Each existing worked example must include a complete problem statement, a worked
solution, and an answer or conclusion. Companions are representative study guides,
not exhaustive solved assessment banks. Preserve readable type, intentional
columns, and complete diagrams; additional US-letter pages are allowed. There is
no fixed four-page limit.

Rebuild with the Overleaf-compatible TeX Live 2025 toolchain, visually inspect
every page, and then replace these copies using the existing filenames.
Divisibility is built from `../divisibility_reference_and_worked_examples.tex`
and saved as `divisibility_core_companion.pdf`. Do not treat an old PDF in this
directory as authoritative when its TeX source has changed.

See `../COMPANION_SELF_CONTAINED_COVERAGE.md` for the example-level review and
local delivery status. A locally replaced PDF does not establish a GitHub push,
Overleaf sync, or public-site update.
