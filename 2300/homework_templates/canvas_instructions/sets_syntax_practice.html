Practice reading the notation and definitions used in the Sets Core. There are 60 short statements. Read each statement as written before choosing an answer.

  • True: a complete proposition that is true.
  • False: a complete proposition that is false.
  • Not a truth-evaluable proposition as written: incomplete, ill-formed, undefined, or containing an unbound variable. This is different from False.

Given: U = {1,2,3,4}, A = {1,2}, B = {2,3}, and C = A. Complements are relative to U. The function f: A → U satisfies f(1) = 2 and f(2) = 4. R = {(1,1),(2,2)} is a relation on A.

Notation: x ∈ A means “x is an element of A”; A ⊆ B means every element of A belongs to B; ∪ means union (in either set); ∩ means intersection (in both sets); A ∖ B means in A but not B; Ac means outside A within U; P(A) means the set of all subsets of A.

Identify the kind of object on each side of a relation. In particular, distinguish an element from a set and membership (∈) from inclusion (⊆).
