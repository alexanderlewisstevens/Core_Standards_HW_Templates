\section*{A. Reconstruct and Challenge Natural-Language Arguments}

\subsection*{A.1 Find the Argument's Spine}
\emph{Archived build logs receive automatic timestamps. Any record with a
trustworthy timestamp can be audited after a failure. Therefore, archived build
logs can be audited after a failure. Because an auditable release process makes
debugging more reliable, the team should archive a build log for every release.}

Identify (i) the main conclusion, (ii) the intermediate conclusion, and
(iii) every stated premise. Draw an arrow diagram showing the support
relationships, then state one plausible unstated bridge premise needed to support
the intermediate conclusion and another needed to support the recommendation.

\subsection*{A.2 Expose Hidden Conditionals}
Let
\begin{itemize}
  \item $T$: a student completes safety training,
  \item $E$: the student may enter the fabrication lab,
  \item $S$: a supervisor is present.
\end{itemize}
Translate each policy into symbols. For the named condition, state which
necessary or sufficient relationship the policy establishes; do not assume a
converse that the policy does not state.
\begin{enumerate}[label=(\alph*)]
  \item A student may enter only if training is complete. (training for entry)
  \item Completing training is enough for entry. (training for entry)
  \item Entry is permitted exactly when training is complete and a supervisor
        is present. (supervision for entry)
  \item A supervisor's presence is enough to permit entry. (supervision for entry)
\end{enumerate}
For one statement, also write its contrapositive and explain why the converse
does not automatically follow.

\subsection*{A.3 Validity, Countermodels, and Repair}
Rewrite each argument in numbered premise/conclusion form. Decide whether it is
deductively valid. If valid, name the inference pattern. If invalid, give a
valuation with true premises and a false conclusion, then make the smallest
clear change that repairs the argument.
\begin{enumerate}[label=(\alph*)]
  \item If the cache is stale, the test fails. The test did not fail. Therefore,
        the cache is not stale.
  \item If the cache is stale, the test fails. The test failed. Therefore, the
        cache is stale.
  \item Either the parser rejected the file or the compiler accepted it. The
        parser did not reject it. Therefore, the compiler accepted it.
  \item If the sensor is calibrated, its readings are stable. If its readings
        are stable, the controller can use them. The sensor is calibrated.
        Therefore, the controller can use the readings.
\end{enumerate}

\section*{B. Logical Reasoning I: Anatomy and Inference}

\subsection*{B.1 Main Conclusion}
\emph{A useful diagram cannot contain every detail of the system it represents.
Adding every detail would make the diagram as complicated as the system and
therefore useless as a guide. Thus, a useful diagram must omit some true
information, even though those omissions can occasionally mislead.}

What is the main conclusion?
\begin{enumerate}[label=(\alph*)]
  \choice{Diagrams occasionally mislead.}
  \choice{A system can be more complicated than its diagram.}
  \choice{A useful diagram must omit some true information.}
  \choice{No diagram can accurately represent a system.}
  \choice{Guides should contain every available detail.}
\end{enumerate}

\subsection*{B.2 Role of a Statement}
\emph{The courtyard should be planted with thyme rather than turf. Thyme needs
less water than turf, and water use must be reduced this summer. Moreover, thyme
tolerates foot traffic.}

In the argument, the claim that water use must be reduced this summer serves as
\begin{enumerate}[label=(\alph*)]
  \choice{the conclusion the argument seeks to establish.}
  \choice{background that is irrelevant to the recommendation.}
  \choice{a principle that, with another premise, supports the recommendation.}
  \choice{a claim offered to refute the fact that thyme tolerates foot traffic.}
  \choice{an example of a planting plan already adopted.}
\end{enumerate}

\subsection*{B.3 Point at Issue}
Nara says, “The city should permit food carts in the central plaza because they
would make lunch less expensive.” Ivo replies, “The plaza's narrow paths would
become dangerously crowded, so food carts should not be permitted there.”

Nara and Ivo disagree about whether
\begin{enumerate}[label=(\alph*)]
  \choice{food carts generally sell less expensive lunches than restaurants do.}
  \choice{the city should allow food carts in the central plaza.}
  \choice{the plaza has narrower paths than other city spaces.}
  \choice{crowded places are always dangerous.}
  \choice{the city regulates restaurant prices.}
\end{enumerate}

\subsection*{B.4 What Must Follow?}
Every accredited sanctuary employs a veterinarian. No organization that trades
animals for profit is accredited. Meadow House is accredited, and River Yard
trades animals for profit.

Which statement must be true?
\begin{enumerate}[label=(\alph*)]
  \choice{River Yard employs no veterinarian.}
  \choice{Meadow House employs a veterinarian.}
  \choice{Meadow House never transfers an animal.}
  \choice{Every organization with a veterinarian is accredited.}
  \choice{River Yard is the only unaccredited organization.}
\end{enumerate}

\subsection*{B.5 Parallel Reasoning}
\emph{Whenever the library hosts an evening lecture, it keeps the west door
open. The west door is not open tonight. Therefore, the library is not hosting
an evening lecture tonight.}

Which argument uses the same pattern of reasoning?
\begin{enumerate}[label=(\alph*)]
  \choice{If the kiln is hot, the studio is open. The studio is open, so the
          kiln is hot.}
  \choice{If the pond freezes, skating is allowed. The pond froze, so skating
          is allowed.}
  \choice{If the bell rings, class ends. Class did not end, but the bell may
          have rung.}
  \choice{If the archive closes, researchers leave. Researchers left, so the
          archive closed.}
  \choice{If the greenhouse is being watered, its pump is running. The pump is
          not running, so the greenhouse is not being watered.}
\end{enumerate}

\section*{C. Logical Reasoning II: Assumptions and Evidence}

\subsection*{C.1 Necessary Assumption}
A school will replace printed notices with an app to reduce paper waste. The
principal concludes that the change will substantially reduce the school's total
paper use.

The conclusion requires assuming that
\begin{enumerate}[label=(\alph*)]
  \choice{every family owns the newest model of phone.}
  \choice{no teacher will ever print an app message.}
  \choice{the app will cost nothing to maintain.}
  \choice{students prefer notifications to paper notices.}
  \choice{eliminating printed notices will produce a substantial net reduction
          rather than merely shift comparable paper use to other tasks.}
\end{enumerate}
Use the negation test in your justification.

\subsection*{C.2 Sufficient Assumption}
If the supplier closes, the workshop will miss its deadline unless it has enough
stored oak. The supplier will close. Therefore, the workshop will miss its
deadline.

Which added assumption makes the conclusion follow logically?
\begin{enumerate}[label=(\alph*)]
  \choice{Oak is the workshop's most expensive material.}
  \choice{The supplier has closed before.}
  \choice{The workshop does not have enough stored oak.}
  \choice{The deadline cannot be extended.}
  \choice{The workshop uses no other supplier.}
\end{enumerate}
Formalize the completed argument in your justification.

\subsection*{C.3 Diagnose the Flaw}
Eight members of the robotics club tried a new coding tutorial, and seven rated
it highly. The tutorial will therefore be popular with nearly all first-year
students.

The argument is most vulnerable because it
\begin{enumerate}[label=(\alph*)]
  \choice{treats a selected, very small group as representative of a broader
          population.}
  \choice{attacks the club members rather than their ratings.}
  \choice{assumes that what happens later caused what happened earlier.}
  \choice{uses the term tutorial in two different senses.}
  \choice{draws a conditional conclusion from a universal premise.}
\end{enumerate}

\subsection*{C.4 Strengthen}
After a ceramics studio installed a new ventilation system, reports of headaches
among its evening students decreased. A researcher concludes that the
ventilation change caused the decrease.

Which fact most strengthens the conclusion?
\begin{enumerate}[label=(\alph*)]
  \choice{Some students prefer working with porcelain.}
  \choice{Comparable nearby studios that did not change ventilation showed no
          similar decrease during the same period.}
  \choice{The studio replaced its kilns several years earlier.}
  \choice{Evening classes are shorter than weekend workshops.}
  \choice{Students report symptoms electronically.}
\end{enumerate}

\subsection*{C.5 Weaken}
An editor concludes that articles with shorter headlines attract more readers
because, in last month's issue, articles with headlines under six words received
more online views than articles with longer headlines.

Which statement most weakens the conclusion?
\begin{enumerate}[label=(\alph*)]
  \choice{Some short headlines contain uncommon words.}
  \choice{The magazine publishes twelve issues each year.}
  \choice{The most-viewed articles were promoted prominently on the home page,
          while most articles with longer headlines were not.}
  \choice{Many readers access the magazine on phones.}
  \choice{Editors sometimes revise headlines before publication.}
\end{enumerate}

\section*{D. Logical Reasoning III: Principles and Explanations}

\subsection*{D.1 Principle Support}
A museum promises to evaluate contemporary art by artistic merit. A reviewer
argues that the museum therefore should not reject a sculpture merely because
its message is unpopular, provided that displaying it would create no safety
hazard.

Which principle most strongly supports the reviewer's reasoning?
\begin{enumerate}[label=(\alph*)]
  \choice{Museums should exhibit every work submitted by a professional artist.}
  \choice{An institution should apply its stated selection criteria even when
          doing so produces controversy.}
  \choice{Public institutions should avoid taking positions on disputed questions.}
  \choice{Safety concerns are never relevant to artistic decisions.}
  \choice{A museum's most popular exhibits are generally its most valuable ones.}
\end{enumerate}

\subsection*{D.2 Resolve the Discrepancy}
A ferry operated fewer hours in May than in April, yet it carried substantially
more passengers in May. Its fare and passenger capacity did not change.

Which fact best resolves the apparent discrepancy?
\begin{enumerate}[label=(\alph*)]
  \choice{The ferry carried less freight in May.}
  \choice{Its crew worked the same shifts in both months.}
  \choice{A commuter-rail station opened beside the ferry terminal in May,
          bringing many new riders.}
  \choice{Fuel cost the ferry operator more in May.}
  \choice{The ferry's timetable used a new typeface in May.}
\end{enumerate}

\subsection*{D.3 Parallel Flaw}
Every cedar in the park is a tree, and some trees in the park are diseased.
Therefore, some cedars in the park must be diseased.

Which argument contains the same flaw?
\begin{enumerate}[label=(\alph*)]
  \choice{Every violin is an instrument, and some instruments in the shop are
          damaged; therefore, some violins in the shop are damaged.}
  \choice{Some buses are electric, and every electric vehicle is quiet;
          therefore, some buses are quiet.}
  \choice{No ceramic cups are flexible, and this cup is ceramic; therefore,
          this cup is not flexible.}
  \choice{Every comet orbits the Sun, and object K is a comet; therefore,
          object K orbits the Sun.}
  \choice{Some editors are poets, and some poets are teachers; therefore, some
          editors may be teachers.}
\end{enumerate}

\subsection*{D.4 Method of Reasoning}
A theorist defines creativity as producing something new in order to win
approval. An isolated mathematician, however, develops a genuinely new proof
solely from curiosity, and the work is still creative. The definition is
therefore inadequate.

The argument proceeds by
\begin{enumerate}[label=(\alph*)]
  \choice{claiming that approval is impossible to measure.}
  \choice{showing that everything new is automatically valuable.}
  \choice{presenting a plausible creative case that lacks the stated motive.}
  \choice{arguing that curiosity and approval are identical motives.}
  \choice{appealing to the theorist's lack of mathematical expertise.}
\end{enumerate}

\subsection*{D.5 Complete the Argument}
A tutoring company claims that its service is the best because it charges the
highest fee. Its spokesperson adds that any equally good competitor would
necessarily charge at least as much. The reasoning is circular because it
\begin{enumerate}[label=(\alph*)]
  \choice{confuses the best current service with the best imaginable service.}
  \choice{infers a property of the company from a property of each tutor.}
  \choice{gives premises that contradict one another.}
  \choice{assumes the connection between high price and high quality that the
          conclusion needs.}
  \choice{ignores the possibility that every tutoring service is ineffective.}
\end{enumerate}

\section*{E. Integrated Evaluation and Revision}

\subsection*{E.1 Cause or Correlation?}
\emph{Students who enabled calendar reminders submitted more work on time than
students who did not. Thus calendar reminders cause timely submission.}

State the conclusion and explain why the evidence alone does not establish it.
Give one plausible common-cause or selection explanation. Then state one new
piece of evidence that would strengthen the causal claim and one that would
weaken it.

\subsection*{E.2 Apply a Principle}
Principle: \emph{When a policy imposes a serious burden on people who cannot
reasonably avoid it, the policy should be adopted only if its expected benefit
is comparably serious.}

Which judgment most directly applies the principle?
\begin{enumerate}[label=(\alph*)]
  \choice{A library should rearrange shelves because the new order looks cleaner.}
  \choice{A school should not require an expensive device for a minor
          convenience when some students have no practical alternative to
          buying it.}
  \choice{A city should choose the least expensive paint for every public
          building.}
  \choice{A club may change its logo whenever a majority prefers a new design.}
  \choice{A restaurant should offer more desserts when desserts are profitable.}
\end{enumerate}
Map each condition in the principle to a stated fact in the best application.

\subsection*{E.3 Analyze and Improve an Op-Ed Argument}
\emph{Some students share rooms or equipment and therefore lack a dependable
place to run long programs at home. A pilot last spring kept one lab open late,
and students used it steadily. Any resource that is steadily used is worth its
cost. Students who used the pilot lab also completed more assignments on time
than students who did not use it. Thus the university should keep one computer
lab open overnight during the final two weeks, since the pilot proves that
overnight access improves academic performance.}

\begin{enumerate}[label=(\alph*)]
  \item State the main conclusion and the strongest stated support for it.
  \item Identify the intermediate conclusion, if any.
  \item Identify one ambiguity and one gap in the reasoning.
  \item Does the pilot establish that overnight access \emph{causes} improved
        performance? Explain.
  \item Rewrite the final two sentences to make a careful conclusion that the
        evidence actually supports.
\end{enumerate}
