# Divisibility Core — instructor and grader notes

Private planning document. Do not publish or link for students.

## Live Core structure

- Supervised paper assessment, 20 minutes.
- Exactly five labeled problems on each live form: one selected from each section A–E.
- All parts under one label belong to that single problem.
- A: division algorithm and congruence.
- B: integer representations and base conversion.
- C: modular arithmetic.
- D: Euclidean algorithm and Bézout coefficients.
- E: synthesis and proof.
- Preserve roughly comparable difficulty among the five variants within each section.

## Canvas grade entry

- Enter only `0`, `4`, or `5` on the single Core assignment.
- `0` = Not Yet: fewer than four of the five complete problems are fully correct.
- `4` = Meets: four of the five complete problems are fully correct.
- `5` = Exceeds: all five complete problems are fully correct.
- Do not convert raw points into a percentage and do not create a separate retake assignment.
- A problem counts as fully correct only when all requested parts, work, and justification are present and correct.

## Retakes

- Every retake uses a new complete five-problem A–E form; students do not redo only the missed problem.
- Earning Meets does not exempt any section on an Exceeds attempt.
- A student may attempt a given Core at most once per calendar day.
- A student may attempt a second, different Core on the same day only after passing the first Core attempted that day.
- Rationale: this encourages preparation and reflection after an unsuccessful attempt while allowing a prepared student to make efficient progress after demonstrating mastery.
- All attempts close at the final-exam deadline; the final period is the last opportunity to pass.

## Week 6 teaching alignment

### Tuesday

- Lecture target: use the division algorithm with positive and negative dividends; move among quotient/remainder and congruence forms; convert among binary, octal, hexadecimal, and decimal.
- Explicit examples: one negative-dividend quotient/remainder problem, one three-view congruence problem, and one cross-base conversion.
- Reserve approximately 45 minutes for substantial group practice drawn from sections A and B.

### Thursday

- Lecture target: compute modular expressions efficiently; run the Euclidean algorithm; back-substitute for Bézout coefficients; write short divisibility proofs.
- Explicit examples: one modular-power cycle, one gcd/Bézout computation of live-form scale, and one direct proof from the definition of divisibility.
- Reserve approximately 45 minutes for group practice spanning sections C–E. Each group member should handwrite at least one complete solution.
- If the first Divisibility Core attempt occurs during class, use a distinct `Group Core Divisibility Attempt` activity for collaborative practice. The individual Core remains a separate supervised paper assessment.

## Form assembly and grading checks

- Select one problem from each section A–E; never place multiple variants from one section on the same live form.
- Check that the selected combination is realistically completable in 20 minutes.
- Verify arithmetic and Bézout coefficients before printing.
- Require canonical remainders `0 <= r < b` whenever the divisor is positive.
- For section E, require an explicit integer witness or divisibility definition when the prompt requests it.
