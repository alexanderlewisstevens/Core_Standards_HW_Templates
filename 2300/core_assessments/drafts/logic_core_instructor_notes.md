# Logic Core — instructor notes

Keep this file with faculty materials. The compiled student document is titled
simply **Logic Core** and does not display provenance, answer-key notes, or form
construction directions.

## Timed-form rule

- Each supervised individual attempt is 20 minutes; approved accommodations
  apply.
- Designate one problem from each section A–E, for five problems total.
- A retake uses a complete new five-problem form; students do not retake only an
  unsuccessful section.
- Meets means four of the five designated problems are fully correct. Exceeds
  means all five are fully correct.
- Before using a combination live, solve it under time and confirm that a
  prepared student can complete it in 20 minutes. The B and C variants have
  multiple lettered parts and therefore need particular timing scrutiny.
