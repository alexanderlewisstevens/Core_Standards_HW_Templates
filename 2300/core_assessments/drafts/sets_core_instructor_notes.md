# Sets Core — instructor notes

Keep this file private. It contains form-construction rules, provenance, and
material that may be used for class practice but is not part of the public Core.

## Authoritative mastery targets

The Sets Core includes the elementary function material from Rosen §2.3. A
student who passes the Core can:

1. construct and interpret finite sets using roster and set-builder notation;
   distinguish membership from subset claims; and compute small power sets and
   Cartesian products;
2. translate compound membership formulas into set operations and Venn regions;
3. interpret a relation as a subset of a Cartesian product, move among plots,
   ordered pairs, and quantified statements, and decide whether the relation is
   a function;
4. use domain and codomain correctly; compute images and preimages; and classify
   functions as injective, surjective, bijective, or neither; and
5. prove or refute a short set/function claim by element chasing or a concrete
   counterexample.

Composition, inverse functions, floor/ceiling functions, indexed families of
sets, and the former test-coverage closure problems are useful enrichment or
group-practice material. They are not required Meets targets for this Core.
The closure problems remain available to instructors as transfer problems, but
they must not displace the five essential families on a live form.

## Live-form specification

- Administer each attempt on paper under supervision for **20 minutes**;
  approved accommodations apply.
- Build every live form with **five labeled problems**, one from each section
  A–E of the public bank.
- Each labeled problem is one scoring unit, including all required subparts. A
  partially correct multi-part problem does not count as fully correct.
- Record one holistic Canvas result: **0 = Not Yet, 4 = Meets, 5 = Exceeds**.
  Meets means four of five problems are fully correct; Exceeds means all five
  are fully correct.
- Every retake uses a complete new five-problem form, including a retake after
  Meets to earn Exceeds. Students do not repair or retake only a missed section.
- A student may attempt one Core per day. A second Core on the same day is
  permitted only after the first Core is passed.
- Before using a combination live, solve it under time. Each problem should take
  a prepared student about 3–4 minutes, leaving a small review margin.

## Week 4 instructional sequence

### Tuesday, September 29 — constructions and operations

The first hour should use a small number of explicit examples to accomplish
these goals:

- distinguish `x in A`, `{x} subseteq A`, and `A subseteq B`;
- translate between roster and set-builder notation;
- build a power set and a Cartesian product without losing the empty set or
  ordered-pair order;
- compute union, intersection, difference, and complement; and
- translate a compound membership formula into a set expression and Venn
  region.

Use the final 45–50 minutes for **Week 4 In-Class Practice — Sets and
Functions (Rosen 2.1–2.3)**. It should be sustained group work, not an exit
ticket. A useful packet has one A problem, two B problems, and one short
Cartesian-product/plot preparation problem from C. Keep the Canvas item closed
until halfway through each section's class meeting.

### Thursday, October 1 — relations and functions

The first hour should connect the earlier set language to functions:

- read a relation as a subset of `X times Y`;
- translate among a plot, ordered pairs, and quantified statements;
- explain the role of domain and codomain;
- find images and preimages; and
- distinguish injective, surjective, and bijective functions with witnesses or
  counterexamples.

Use the final 45–50 minutes for **Group Core Sets Attempt**. Randomly give each
group one representative problem from each section A–E. Each student must
handwrite at least one complete solution; a student may then copy a teammate's
solution for additional practice. This is formative group practice, not an
individual Core rating. Keep the Canvas item closed until halfway through each
section's class meeting.

Suggested balanced packets after the public bank and solutions are final:

- Packet 1: A.1, B.3, C.1, D.2, E.2.
- Packet 2: A.4, B.1, C.4, D.5, E.4.

For C.4, the plotted relation has all three outputs for inputs 1 and 2, and
outputs 1 and 2 for input 3. This eight-pair reading is the authoritative key;
older solution text that listed only five pairs was incorrect.

Pilot both packets before use and replace any problem that makes the group task
substantially longer or shorter than the other packet.
