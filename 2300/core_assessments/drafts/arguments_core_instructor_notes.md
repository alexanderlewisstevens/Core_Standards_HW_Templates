# Arguments Core — Instructor Notes

Keep this file private. It contains form-construction rules and answer keys; it
is not student-facing material.

## Live-form specification

- Administer each attempt on paper under supervision for **20 minutes**.
- Build every live form with **five labeled problems**, one from each section
  A–E. Sections B–D are therefore three of the five problems and the majority of
  the form.
- Each labeled problem is one scoring unit, including all of its required
  subparts. A partially correct multi-part problem does not count as correct.
- Record one holistic Canvas result: **0 = Not Yet, 4 = Meets, 5 = Exceeds**.
  Meets means at least four of five problems are fully correct; Exceeds means all
  five are fully correct.
- A retake replaces the entire form. Students do not retake only the missed
  problem or section.
- A student may attempt one Core per day. A second Core on the same day is
  permitted only after the first Core is passed.
- Live forms use new scenarios or instructor-authored adaptations from the same
  problem families. Do not copy or closely paraphrase official LSAC questions,
  stimuli, answer choices, or explanations.

## Timing and selection

The public Core is a practice bank, not a single live form. Do not place the
longest bank prompts on a 20-minute form without shortening them.

- A: use one reconstruction, conditional-classification, or validity task.
  If adapting A.3, use one or at most two of its four arguments, not all four.
- B–D: use one concise Logical Reasoning problem from each section. Require both
  the selected answer and a brief justification.
- E: use a focused evaluation or revision task. If adapting E.3, ask no more
  than two tightly related subparts on one live form.
- Target roughly 3–4 minutes for each B–D problem and 4–5 minutes for each A/E
  problem. Pilot every form before use; revise wording if a prepared student
  cannot finish comfortably in 20 minutes.

## Practice-bank controls

- The authoritative taxonomy contains 21 problem types: A.1--A.3, B.1--B.5,
  C.1--C.5, D.1--D.5, and E.1--E.3.
- Each type contains at least 10 substantively distinct, difficulty-aligned
  problems. The first release therefore has 210 problems.
- Item identifiers use the stable form `A.1.01` through `E.3.10` and must match
  across the TeX, Obsidian solutions, and private grader guide.
- The generated private grader guide is the compact answer key and essential-
  criteria source. The published Obsidian page contains the complete written
  solution for every item.
- The build validator rejects missing solutions or rubrics, duplicate IDs,
  obvious near-duplicates within a type, and imbalanced answer positions.

## Week 3 alignment

- Tuesday, September 22: teach argument anatomy, necessary/sufficient
  conditions, and Logical Reasoning families; use the class-window LawHub
  activity for sustained group practice.
- Thursday, September 24: teach formal reconstruction, validity, flaws, and
  repair; use **Group Core Arguments Attempt** for the final 45–50 minutes.
- Group Core work should use representative A–E practice problems, not a live
  individual Core form. Each student handwrites at least one solution; students
  may copy a teammate's solution afterward for practice.
- Randomly assign one of these five-problem practice packets to each group:
  - Packet 1: A.1.01, B.1.01, C.3.01, D.2.01, E.2.01.
  - Packet 2: A.2.01, B.4.01, C.1.01, D.4.01, E.1.01.
  Each packet has one prompt from every section and enough distinct work for as
  many as five students to handwrite one solution apiece. The concise-answer
  keys are Packet 1: B.1.01 C, C.3.01 A, D.2.01 A, E.2.01 B; Packet 2:
  B.4.01 B, C.1.01 A, D.4.01 A. Grade A.1.01, A.2.01, E.1.01, and all
  justifications against the complete Obsidian worked solutions.
- The Canvas instructor page must include these exact packet selections and
  keys and must remain unpublished.

The entire bank is original course-authored material. Sections B–D use familiar
Logical Reasoning problem families but do not copy or closely paraphrase LSAC or
LawHub stimuli, prompts, answer choices, or explanations. Keep official practice
in LawHub.
