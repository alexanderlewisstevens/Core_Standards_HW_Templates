# COMP 2300 Core Assessments

Use the one-word Canvas labels as the canonical identifiers:

`Logic`, `Arguments`, `Sets`, `Proofs`, `Divisibility`, `Induction`, and `Counting`.

The file order in this directory is not the teaching order. Course sequencing belongs in Canvas, so assessment sources should not regain numeric prefixes.

The current design places `Functions` within `Sets` and elementary `Probability`
within `Counting`. Participation and Practice is a Canvas category rather than a
LaTeX assessment.

These files are public practice sources, not live paper forms. For Logic, staff
designate one problem from each section A--E for a five-problem, 20-minute live
form. Other non-Arguments Cores ordinarily use a 6--8-problem live form assembled
from their labeled source. Arguments is the intentional long-form exception: its
five-section public bank has 21 stable problem types and at least 10 original,
difficulty-aligned problems per type (at least 210 total). It combines formal
reconstruction, Logical Reasoning, causal evaluation, and integrated writing. It
uses no official LSAT/LawHub wording.

Across every Core, one labeled item is one problem. Meets requires all but at most
one problem to be fully correct; Exceeds requires every problem to be fully
correct. Retakes cover the entire live form, and Canvas stores the holistic status
as 0 = Not Yet, 4 = Meets, or 5 = Exceeds.
