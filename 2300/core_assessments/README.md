# COMP 2300 Core Assessments

Use the one-word Canvas labels as the canonical identifiers:

`Logic`, `Arguments`, `Proofs`, `Sets`, `Divisibility`, `Induction`, and `Counting`.

The file order in this directory is not the teaching order. Course sequencing belongs in Canvas, so assessment sources should not regain numeric prefixes.

The intended design places `Functions` within `Sets` and `Probability` within
`Counting`, but those targets are not yet integrated into the current assessment
sources. Participation and Practice is a Canvas category rather than a LaTeX
assessment. `arguments_assessment.tex` is the canonical four-page, instructor-authored
Arguments pool; it uses original analogous reasoning problems rather than official
LSAT/LawHub wording.
