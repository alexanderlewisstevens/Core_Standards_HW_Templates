# Core Assessment Materials

This repository contains the student-facing LaTeX sources used to build COMP 2300 and COMP 3004 assessments, practice sets, reference sheets, and course highlights.

## COMP 2300 naming

Assessment names are topic words rather than sequence numbers. This keeps the source files stable when the teaching order changes.

| Teaching order | Canvas name | Canvas assignment | Source status |
| --- | --- | --- | --- |
| 1 | Logic | `2057866` | `2300/core_assessments/logic_assessment.tex` |
| 2 | Arguments | `2057865` | `2300/core_assessments/arguments_assessment.tex`; original analogous reasoning problems only |
| 3 | Proofs | `2057867` | `2300/core_assessments/proofs_assessment.tex` |
| 4 | Sets | `2057868` | `2300/core_assessments/sets_assessment.tex`; functions targets still need to be integrated |
| 5 | Divisibility | `2057869` | `2300/core_assessments/divisibility_assessment.tex` |
| 6 | Induction | `2057870` | `2300/core_assessments/induction_assessment.tex` |
| 7 | Counting | `2057871` | `2300/core_assessments/counting_assessment.tex`; probability targets still need to be integrated |

Participation and Practice is a Canvas category, not a Core assessment or a
LaTeX source. The Canvas assignment IDs above identify the Autumn 2026 course
records; the one-word names remain the durable identifiers across terms.

The private Obsidian vault contains solution notes. Do not add solution keys to this public repository.

## Layout

- `2300/core_assessments/`: standalone assessment sources
- `2300/counting_problem_sections/`: sections included by the Counting assessment
- `2300/cheat_sheets/`: student reference sheets
- `2300/homework_templates/`: reusable homework scaffolds
- `3004/`: COMP 3004 practice materials
- `course_highlights/`: chapter summaries, definitions, and quiz templates
- `in_progress/`: drafts that are not ready for student use
- `archive/`: retained historical source snapshots

LaTeX build products, PDFs, macOS metadata, and editor workspace files are intentionally ignored.
